This project utilises 4 machine learning models to predict heart disease using a variety of health variables and demographic factors.
Each model was then compared to determine which had the strongest predictive performance. SVM (Support Vector Machine), achieved the highest classification accuracy. 
This data was originally collected as part of the Coronary Risk Factor Study in South Africa. However, it is publicly available, and I sourced it from Kaggle.
(https://www.kaggle.com/datasets/waalbannyantudre/south-african-heart-disease-dataset)
